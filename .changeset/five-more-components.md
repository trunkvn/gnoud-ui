Add Separator, Meter, Toggle, Slider and AlertDialog. Separator is a ruled line, horizontal or vertical. Meter is a gauge for a value in a known range (Progress stays for work that finishes). Toggle is a pressed/unpressed button, and `ToggleGroup` joins several into one strip that picks one or many. Slider picks a number or a range, with a named thumb per value. AlertDialog is a dialog that asks for a decision: announced as an alert dialog, with no corner "×", and the veil does not dismiss it. The library now has 25 components.
